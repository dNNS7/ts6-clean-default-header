# Clean Default Header

A minimal theme for **TeamSpeak 6** that hides the floating server header bar while keeping the default TeamSpeak look intact.

## Features
* Hides the floating server header bar (`.ts-server-header`) for a cleaner channel view
* Keeps the default TeamSpeak 6 layout, colors, and structure unchanged
* Lightweight CSS-only theme (`style.css`)

## Installation
1. Download the `.zip` archive from the [latest release](https://github.com/dNNS7/ts6-clean-default-header/releases/latest) or clone the repository.
2. Extract or copy the `com.legendsts.cleanheader` folder into your TeamSpeak 6 extensions directory: `%AppData%\TeamSpeak\Default\extensions\`
3. Open TeamSpeak 6 and go to **Settings → Appearance → User Theme**.
4. Select **Clean Default (No Header)** and restart TeamSpeak 6 if needed.
